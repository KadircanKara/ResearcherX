### Frozen contract — Projects (M1)
```
GET    /v1/projects                          -> ProjectOut[]      (projects I'm a member of)
POST   /v1/projects        {title, description?, topic_keywords?[]} -> ProjectOut (caller becomes owner member)
GET    /v1/projects/{id}                      -> ProjectDetailOut  (members + counts; any member)
PATCH  /v1/projects/{id}   {title?, description?, topic_keywords?[]} -> ProjectOut (owner|editor)
DELETE /v1/projects/{id}                       -> 204              (owner)
GET    /v1/projects/{id}/members              -> MemberOut[]       (any member)
POST   /v1/projects/{id}/members  {user_id, role} -> MemberOut     (owner; role in editor|commenter|viewer)
PATCH  /v1/projects/{id}/members/{user_id} {role} -> MemberOut     (owner)
DELETE /v1/projects/{id}/members/{user_id}     -> 204              (owner; cannot remove last owner)

Role = "owner" | "editor" | "commenter" | "viewer"
ProjectOut       = {id, title, description, topic_keywords[], my_role, counts:{members,papers,chats}, created_at, updated_at}
ProjectDetailOut = ProjectOut + {members: MemberOut[]}
MemberOut        = {user: UserOut, role}
```
(`papers`/`chats` counts are 0 in M1 — those tables arrive in M3/M6; the fields exist now so the UI is stable. Non-members get 404 on a project, not 403, to avoid leaking existence.)
